# Contributing / 参与贡献

Open an issue or pull request with a minimal reproduction. Please avoid uploading private manuscripts, account identifiers, tokens, or personal screenshots.

Run `npm ci`, `npm test`, `npm run build`, and `npm run build:demo`. Character changes must preserve unchanged text; a stale or ambiguous match must never trigger a write. Keep the existing one-item-at-a-time flow and project/file ownership checks. Bulk acceptance requires explicit user confirmation of its pending set and scope, uses the same guarded per-item writes, and must not replay approval after stop, undo or restart. Include tests for behavioral changes and preserve third-party licenses.

欢迎提交 Issue 或 PR，请用最小样例复现，避免上传私人论文、账号标识、令牌或个人截图。提交前运行上述检查；字符修改需保留未变文本，过时或不唯一的匹配不得写入，并保留逐项接受、项目/文件身份检查和第三方许可。批量接受须由用户明确确认待处理集合与范围，逐项使用相同写入核验；停止、撤销或重启后不得复用旧批量授权。
